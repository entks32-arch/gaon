# 🏗️ 시공 게시판 시스템

사용자와 관리자를 구분한 시공 게시판 웹 애플리케이션입니다.

## 📋 주요 기능

### 👤 사용자 기능
- **로그인**: 비밀번호 `1478`로 로그인
- **게시글 조회**: 관리자가 등록한 모든 게시글 열람
- **키워드 검색**: 시공 내용, 견적, 실측 여부로 검색
- **이미지 확대**: 게시글의 이미지를 클릭하여 크게 보기

### 👔 관리자 기능
- **로그인**: 비밀번호 `8810`으로 로그인
- **게시글 등록**: 새로운 시공 게시글 작성
- **게시글 삭제**: 등록된 게시글 삭제
- **키워드 검색**: 게시글 검색
- **이미지 확대**: 게시글의 이미지를 클릭하여 크게 보기

### 📝 게시글 정보
각 게시글에는 다음 정보가 포함됩니다:
- **시공 내용**: 시공 작업에 대한 상세 설명
- **견적**: 예상 또는 확정 견적 금액
- **실측 여부**: 실측 완료 여부 (했음/안했음)
- **이미지 첨부**: 여러 개의 시공 관련 이미지 (선택사항)

## 🚀 실행 방법

### 1. 로컬 서버 실행
```bash
cd /home/user/webapp
python3 -m http.server 8000
```

### 2. 브라우저에서 접속
```
http://localhost:8000
```

## 💾 데이터 저장

- **로컬 스토리지 사용**: 모든 게시글은 브라우저의 로컬 스토리지에 저장됩니다
- **영구 저장**: 브라우저를 닫아도 데이터가 유지됩니다
- **이미지 저장**: 이미지는 Base64 형식으로 변환되어 저장됩니다

## 🎨 주요 기능 상세

### 관리자 - 게시글 등록
1. 로그인 후 "➕ 게시글 등록" 버튼 클릭
2. 시공 내용 입력 (필수)
3. 견적 입력 (필수)
4. 실측 여부 선택
5. 이미지 파일 선택 (여러 개 가능)
6. "등록" 버튼 클릭

### 관리자 - 게시글 삭제
1. 삭제할 게시글의 "🗑️ 삭제" 버튼 클릭
2. 확인 대화상자에서 확인

### 사용자/관리자 - 검색
1. 검색창에 키워드 입력
2. 자동으로 필터링된 결과 표시
3. 검색어 삭제시 전체 목록 표시

### 이미지 확대 보기
1. 게시글의 이미지 썸네일 클릭
2. 모달 창에서 원본 크기로 보기
3. 모달 외부 또는 X 버튼 클릭하여 닫기
